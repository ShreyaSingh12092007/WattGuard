# WattGuard ⚡

WattGuard is a software-based Smart Building Energy Management System.

It uses energy, lighting, indoor environmental, and weather-related data
to predict energy demand, identify peak periods, and recommend intelligent
load-management actions.

## Main Features

- Energy consumption prediction
- Peak-demand detection
- Smart control recommendations
- Baseline vs. optimized energy comparison
- Simulated energy-saving estimation
- Interactive Streamlit dashboard
- Proposed BMS integration architecture

## Prototype

The current prototype uses the UCI Appliances Energy Prediction dataset.

The simulated savings scenario assumes that 15% of flexible consumption
during the identified peak period can be shifted or reduced.

This is a simulation assumption and is not a measured real-world saving.
